# Фильтрация изображений

Ruslan Papina, группа М25-555

Домашнее задание: исследование фильтров выделения границ, сглаживания и повышения резкости, а также влияния их параметров (размер окна, шаг, σ, коэффициент усиления и т.д.).

Отчёт: [report.pdf](report.pdf)

## Структура

- `filters.py` - весь код: подготовка изображения, своя свёртка с шагом (stride), применение фильтров и построение сеток
- `images/chelsea.png` - исходное изображение (тестовое изображение `chelsea` из scikit-image, 451x300)
- `images/input_256.png` - изображение после обрезки и приведения к 256x256
- `results/` - сетки с результатами (номера совпадают с рисунками в отчёте)

## Запуск

```
pip install -r requirements.txt
python filters.py
```

Скрипт запускается из корня репозитория, картинки сохраняются в `results/`. Перед экспериментами скрипт проверяет, что своя функция `conv2d` совпадает с `cv2.filter2D`, `cv2.Sobel` и `cv2.GaussianBlur`.
